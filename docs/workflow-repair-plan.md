# 配置、预览、发布与 Kindle 更新修复计划

日期：2026-09-05。用户已授权实施，并指定交给 gpt-5.6-luna、max 推理强度的独立任务。实施在独立 worktree 进行，完成后由协调任务检查并合并到 main。

## 目标与完成标准

用户在组件属性中配置数据来源，看到真实数据预览，点击发布后更新设备固定图片地址；后台按已发布配置周期更新，Kindle 按客户端日程取图。正常使用不要求手填连接 ID 或在聊天里提供密钥。

现有代码提供 Fastify/SQLite、登录、草稿、PNG 任务、发布、设备取图和真实 Codex 数据。Google OAuth、天气 HTTP 传输和相册管理尚未接入；当前天气“测试连接”只有本地字段检查，必须替换。测试通过不代表真实供应商或设备已验证。

## 实施顺序

### 1. 服务端连接与天气完整流程

- 复用现有连接版本与 CredentialStore，实现天气连接的创建、选择和安全凭据写入。浏览器 GET 只返回脱敏连接状态；部署主密钥在数据库外持久保存，重启可解密；缺失/错误主密钥明确报错。
- 面板提供连接名称、API Host、API Key 专用输入和已有连接选择。连接 ID/版本由系统绑定。秘密不进入草稿、撤销、导出、浏览器持久存储、日志和渲染消息。
- 实现真正的测试接口，支持未保存输入或已保存连接，测试不保存连接、不更改草稿、不发布。显示测试中、真实天气摘要、认证/位置/限流/超时等失败状态；输入改变后旧测试结果不得覆盖新状态。
- 核对和风官方当前文档，兼容所选项目支持的 API 版本和认证；实现允许目标/路径、实际 DNS/IP 约束、禁止重定向、总超时和解压后响应上限。不得对猜测 Host 发送用户凭据。
- 将天气采集接入 collectWidgetData、预览、发布和周期任务，复用缓存与在途请求。缓存按连接版本、凭据修订、位置、单位隔离；认证失效清理不该复用的数据。
- 真实联调需要用户在面板填写有效 Host/Key。缺少外部配置不能阻止代码、模拟上游集成测试和 UI 完成，也不能伪报真实联调成功。

### 2. 自动真实预览与一键发布

- 保留拖动即时几何反馈。配置停止输入或拖动落下后防抖生成服务端 PNG；无效字段不触发取数，失败显示可理解原因，保留旧预览并标记过期。
- 同时处理编辑修订、同修订不同请求和连接变更造成的响应乱序，避免旧图覆盖新图；合并请求避免每次拖动都请求供应商。
- 点击发布自动完成当前有效草稿的保存与发布，无需先点保存。固定点击时的配置，遇到修订冲突明确停止；发布期间继续编辑不会混入本次发布或被响应覆盖。
- 成功后展示发布修订和生成时间；失败保留旧发布结果。草稿和测试始终不影响设备图片。

### 3. 图片相册与目录

- 提供受鉴权保护的相册创建、上传、图片列表和已有相册选择；目录采用管理员明确登记的服务端路径，随后由 ID/版本引用。
- 复用现有扫描、sharp 解码和轮换逻辑，补资源管理、输入/输出大小限制、原子落盘、引用保护和明确错误。
- 接入数据采集和 PNG；按配置随机/顺序/固定选图，保存轮换状态与整轮快照，避免重新预览导致随机跳变或破坏不重复规则。
- 浏览器文件选择用于上传，不宣称浏览器能选择任意服务器目录。验证坏图、空目录、路径越界及资源被移除。

### 4. Google 日历

- 提供 Google OAuth 应用配置状态与“连接 Google 日历”操作，完成管理员会话绑定 state、固定回调、授权码交换、加密 token、刷新及撤销/重连。
- 从真实授权接口读取日历列表，用户勾选日历，不手填连接 ID。实现受限 HTTP 事件采集、分页上限、重复事件、时区、授权失效和缓存隔离，接入预览/周期任务。
- 缺少 Google 客户端配置或用户授权时，界面明确引导；继续完成不依赖该信息的实现。实际登录授权由用户完成，不把模拟 OAuth 当作真实证据。

### 5. 周期更新与设备状态

- 后台按已发布配置调度天气、日历和图片刷新，区分供应商采集间隔、PNG 生成和 Kindle 取图周期；重启后恢复，限制并发。
- 界面提供周期设置与最近生成/失败状态；设备页说明固定图片地址、客户端刷新配置及最近取图时间。
- HTTP GET 仅服务已有 PNG/304，不能触发供应商采集。服务端发布成功只证明图片可取，最近取图只证明设备请求过；没有屏幕回执不得显示“Kindle 已显示成功”。
- 本轮落实现有 Kindle 周期拉取流程。立即唤醒/推送需要设备可达和专用机制，不能用按钮伪装；若没有现成机制，准确显示“等待设备下次取图”。不刷固件、不新增公网暴露。
