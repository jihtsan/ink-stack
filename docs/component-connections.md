# 组件连接、入口与密钥配置

状态：首版软件已实现并进入本地验收（2026-09-05）。下文保留原设计约定；实际交付范围、命令和验证证据以 [验收记录](verification.md) 与 [部署说明](deployment.md) 为准，Kindle 实机仍待验证。

## 配置界面

组件设置分为“显示”和“数据连接”：显示设置管理标题、单位、布局等；数据连接管理来源类型、连接名称、服务入口、认证方式、密钥和测试状态。本地文字、日期、待办不显示无用的连接表单。

用户可以在组件设置内新建连接，不必先离开编辑器。多个组件可以选择同一连接，例如两个城市共享一个天气服务账号。新建连接成功后只绑定当前草稿；必须发布看板才改变设备使用的来源。

| 字段 | 示例 | 保存位置 |
| --- | --- | --- |
| 普通显示配置 | 标题、城市、单位 | 组件 config |
| 连接引用 | connectionId、connectionRevision | 组件 config |
| 非敏感入口与参数 | baseUrl、适配器允许的资源路径 | 服务端连接版本 |
| 认证参数 | API key、Bearer token、私有订阅完整 URL | 服务端加密凭据存储 |
| 状态 | 是否已配置、最近测试时间、错误类别 | 管理接口的脱敏响应 |

“入口”指服务端获取数据的 API 地址、适配器允许的资源路径或订阅源，不代表 Kindle 可以点击打开网页，也不代表任意网页 URL 都能自动转换为组件。需要相应的数据解析适配器。

## 组件文件约定

数据型组件按需增加 connection.schema.json，描述适配器支持的入口、认证方式和字段；秘密字段由可信元数据标记为 secret。config.schema.json 仍只定义普通配置与连接引用。manifest 声明支持的连接类型；相同类型的连接才可复用。

catalog 注册表可以向管理前端提供字段定义和输入提示，不提供已保存的密钥值。所有 schema 都随项目注册和构建，不接受用户上传 schema 后动态编译。认证 header 名称和取数方式由受信任的适配器决定，不提供任意脚本或 shell 命令输入。

## 密钥录入与保存

新密钥由用户在登录后的管理页录入，通过专用写入接口发送给后端。输入值只保留在当前表单内存；成功保存或关闭表单后清除，不写 localStorage、看板草稿、撤销历史或导出文件。

保存后只显示“已配置”，不回传原文。更新操作明确区分 keep、replace、clear；空输入不代表清除，界面上的掩码不能被当作真实密钥再次提交。

后端使用经过认证的加密方式保存可恢复凭据，部署主密钥存放在数据库之外的受保护配置中。运行时只有取数层解密并按需使用，渲染输入不包含凭据。主密钥不可用时报告连接不可用，不静默退回明文；备份恢复说明必须覆盖主密钥的独立保管。

私有订阅 URL、带 token 的查询串和签名 URL 本身也可能是凭据，不能作为普通 baseUrl 回显。普通入口拒绝 URL 内嵌用户名、密码或认证参数；需要此类服务的适配器使用独立秘密字段组装请求。

请求体、认证 header、完整秘密 URL 和上游错误正文不得原样记录或返回。连接管理响应只提供配置状态，不含秘密尾号。已登录浏览器仅在新录入时短暂接触用户输入，不具备读取已保存密钥的接口。

## 入口校验与连接测试

输入接口地址不自动发起请求；点击“测试连接”或明确保存后，服务端才按适配器执行受限的只读取数。测试不保存新配置、不发布图片，并不证明 Kindle 已刷新。

测试可以使用未保存的输入或指定已保存连接；明确区分认证失败、地址不可达、响应格式不符和成功。测试结果不回显密钥或原始响应，只提供脱敏摘要和规范化天气快照用于当前编辑器的临时预览，并绑定测试的输入修订，过期结果不能覆盖新编辑状态。测试仍不创建连接、不保存草稿或发布图片；要生成 PNG 或发布，必须显式保存连接。

和风天气组件的城市模式先通过服务端 GeoAPI 查询候选位置；用户必须选择一个候选，组件才会把非敏感的 `locationId`、名称、纬度和经度写入当前草稿，点击“保存草稿”后才持久化。候选列表只返回经过白名单清理的字段，API Key/JWT、原始响应和秘密引用不会进入浏览器、看板 JSON 或 PNG。选中后天气采集优先使用该明确 Location ID（v7）或其固化经纬度（v1），不会再次把模糊城市名交给天气接口。

平台限制协议、目标、超时、响应体大小和并发。默认禁止重定向，凭据绑定已配置目标，不转发给其他来源。域名解析后的地址也要验证，并在建立连接时约束实际目标，避免只检查 URL 字符串。

局域网服务是支持场景，通过部署配置允许明确的主机/IP 和端口；不提供任意内网探测能力。禁用 file 等非 HTTP 协议及基础设施元数据地址。携带凭据优先使用 HTTPS；可信局域网 HTTP 需明确配置，其传输不保密。

## 草稿、复用与刷新

入口、认证方式、账号绑定等连接设置按版本保存，组件引用具体版本。修改这些设置创建新版本，只更新当前草稿中的绑定；发布前旧画面仍使用旧版本。旧连接版本被草稿或已发布看板引用时不能删除。

单独的“替换密钥”属于连接维护，会影响使用该凭据的所有组件后续取数，界面列出受影响实例。只允许在相同来源身份下轮换；切换账号或目标应创建新连接版本。轮换后失效相关缓存并重新验证身份，不能显示旧账号缓存。现有 PNG 保留到下一次成功生成。

缓存按连接 ID、连接版本、认证修订、实际账号身份及业务参数隔离。连接测试和正常采集都限频，同来源请求可以复用。删除组件不自动删除共享连接或凭据；无引用资源由管理界面单独清理。

## Codex 的区别

Codex 额度首版选择已配置的本机 App Server 连接与额度分组，不显示一个通用 OpenAI API key 输入框来代替账号登录。已有额度读取方案见 [Codex 组件](../packages/widgets/src/codex-usage/README.md)。

将来增加远程采集器时，才为该连接类型提供采集入口与 InkStack 连接令牌；这不是 Codex 账号的认证密钥。组件连接配置能力不意味着远程采集器已经实现。

## 实施与验收

- 组件中可新建、测试、保存及复用受支持的连接；本地组件不要求连接。
- 字段校验同时覆盖入口、认证模式与必填秘密；未配置必填密钥不能伪报测试成功。
- 保存后重开设置只显示已配置；keep、replace、clear 行为独立且可验证。
- 看板 JSON、浏览器持久存储、日志、错误、渲染消息和 PNG 均不含凭据。
- 测试、修改草稿及创建连接版本不改变已发布来源；凭据轮换明确影响范围并失效缓存。
- 复用、账号切换、非法目标、超时、重定向、凭据缺失和解密失败均有明确结果。
