## 对应行为

| 参考组件 / 设置 | InkStack 实现 |
| --- | --- |
| 天气 2×2 综合看板 | 城市、温度、天气、AQI/PM2.5、24 小时温度图、未来五天、UV；模块独立开关 |
| UV 与穿衣参考 | UV 使用实际每日接口字段；衣着参考按当前温度与雨况简单估计，并明确标为参考 |
| 天气图标 | Apache-2.0 Material Symbols，线框、点阵、实体 |
| Floyd–Steinberg | 服务器将天气卡片单独量化为 16 级灰度并做误差扩散，边界不影响相邻组件 |
| 采集频率 | 默认两小时，可选一小时、六小时或自定义；新鲜期自动覆盖采集间隔 |
| 月历 2×2 | 浅灰月历矩阵、相邻月份灰字、黑色方块高亮今日；原 Google 日程连接继续可用 |
| Codex 2×2 | 两个真实额度窗口、剩余百分比和重置提示；保留 2×4 默认尺寸 |
| 相纸照片 | 可开关相纸边框、选择裁切方式、填写题字；旧实例保持原样 |
| 日期栏 | 可添加日期、星期、副标题；没有时钟、电量、耗电估算 |

数据更新时间、日程时间和额度重置时间仍属于必要数据说明。服务器定时生成 PNG 与 Kindle 获取、消残影是不同动作；参考中的暴雨触发硬件刷新没有接入。参考中的美元余额、RPM、历史 Tokens 柱图、已授权标记、农历/节气和电池数字不作为真实数据复制。实际显示已有数据，缺失则显示不可用状态；图片不可冒充已推送到设备。

## 兼容与边界

旧天气实例缺少综合模式时继续采用 daily；所有新增配置可选，不需迁移已保存看板。天气图标和绘制入口可在浏览器使用，数据连接与密钥仍只在服务器。天气各模块并行读取，单项失败只影响该模块；模块选择参与缓存键。

所有实例仍保存整数网格位置，前后端均校验支持尺寸、重叠、越界和最小像素。相册不内置 Stitch 照片；它仅用于隔离的视觉验证，正式卡片展示用户选择的图片。

## 验证

Node 24.20.0 下运行类型检查、生产构建、导入边界检查以及 202 项测试。macOS 测试设置 `TMPDIR="$PWD/.local/stitch-tests"`，避免系统临时目录别名触发现有相册根目录校验；未为此修改生产路径安全检查。

浏览器使用隔离数据目录和 1072×1448 / 4×5 看板，验证添加日期及四卡、2×2 切换、天气模块开关、预设和自定义频率、题字、保存与 PNG。完整数据画面通过隔离服务器的 `dataProvider` 注入标记为示例的天气和额度，并非真实外部 API 验收。Kindle 型号、固件、消残影和续航仍未实机验证。
