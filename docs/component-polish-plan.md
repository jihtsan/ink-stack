# 组件视觉优化

目标：延续已选 Stitch 工作台设计，优化现有四组件，包含浏览器布局示意及实际 PNG。

- 日期：独立主日期、副标题和星期，短日期/完整日期/数字格式一致，小尺寸不溢出。
- 待办：标题与完成数、分隔线、清晰条目与底部剩余项；浏览器遵守未完成优先和最大显示设置。
- 文字：字号、对齐、边框、背景的编辑反馈与配置一致；较短尺寸避免标题挤出正文。
- Codex：标题/账号/状态分层，使用当前匹配编辑修订的实际PNG区域展示额度；无当前PNG时明确为空状态，不虚构额度。
- 保留持久化/数据加载契约与服务端凭据边界，不新增组件类型或依赖。

先补浏览器组件语义回归与渲染尺寸回归，再修改。验证包含现有测试、严格类型/边界检查、独立测试数据库中的桌面/小尺寸/手机及服务端PNG视觉检查。每轮视觉结论记录在 `.omx/state/component-polish/ralph-progress.json`，不发布到现有Kindle看板。
