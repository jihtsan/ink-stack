# Stitch 工作台 UI 重写

目标：将现有 React 编辑器改为选定 PaperCraft Studio 的视觉布局，保留墨栈中文品牌及现有四组件能力。

参考：assets/stitch/14793854115977674732/1d754e6f1bfe47b189d2dd5f2150286d/code.html。下载截图主体为空，使用本地 HTTP 渲染 HTML 作为视觉参考。

实现：紧凑顶栏、浅灰背景、独立圆角组件卡片和筛选、中央黑色 Kindle 设备画框、蓝色选择反馈、右侧属性面板、底部状态。组件搜索/分类/尺寸筛选、图层选择、网格开关、缩放、PNG 预览/下载和设备信息切换使用真实状态。

产品适配：仅展示真实的文字、日期、待办、Codex 额度组件；不引入参考中的假日历授权、天气、电池或收费额度数据。现有网格、保存、渲染、发布和凭据契约保持不变。窄屏改为顺序布局，不照搬参考的横向溢出。
