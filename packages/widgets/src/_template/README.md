# 新组件目录模板

这是一份开发说明模板，不是可执行脚手架；不会出现在组件库中。

实施时复制该目录并替换 README，按需创建：

- `manifest.json`：稳定类型、名称、代码/配置版本、支持尺寸和默认尺寸。
- `config.schema.json`：配置字段和校验规则。
- `connection.schema.json`：可选，声明服务入口、认证方式及秘密输入字段；实际秘密不得放入默认值或样例。
- `defaults.json`：通过校验的默认配置。
- `render.ts`：接收区域、配置和数据的纯绘制入口。
- `server.ts`：仅数据型组件需要，负责后端取数。
- `views/`：不同尺寸布局确有差异时再拆分。
- `fixtures/`：正常、长文本、空数据、错误或过期样例。

在公共元数据注册表和后端注册表中添加对应记录，再构建和验证。接口和具体依赖以实施阶段确定的共享契约为准。

README 至少记录用途、支持尺寸、配置、数据来源、更新时间含义、失败行为及样例。规则见 [组件开发文档](../../../../docs/widgets.md)。

需要外部数据时说明支持的连接类型、入口格式、必填密钥与只读测试方式。连接与秘密通过平台管理，配置仅保存引用，具体规则见 [连接配置](../../../../docs/component-connections.md)。
