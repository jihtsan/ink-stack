- Variant: Material Symbols Outlined, default 24 px (weight 400, fill 0).
- Source path for each icon: `symbols/web/<name>/materialsymbolsoutlined/<name>_24px.svg`
- Local filenames remove only the `_24px` suffix; SVG contents are unmodified.

The application serves these files locally at `/icons/<name>.svg`, avoiding a
runtime dependency on an external icon font. CSS masks may be used to tint them
with the surrounding text color.

Included icons: `grid_view`, `tablet_android`, `tune`, `calendar_month`,
`check_circle`, `terminal`, `text_fields`, `add`, `search`, `undo`, `save`,
`visibility`, `upload`, `download`, `settings`, `layers`, `close`, `check_box`,
`check_box_outline_blank`, `drag_indicator`, `zoom_in`, `zoom_out`, `info`.
