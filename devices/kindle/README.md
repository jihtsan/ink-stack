# Kindle 接入

状态：接入方案草案，尚未进行实机验证。

## 初期客户端

使用 [kndl-online-screensaver](https://codeberg.org/cryptomilk/kndl-online-screensaver)。InkStack 负责生成和提供 PNG；该客户端负责在设备上定时获取图片、显示屏保和管理唤醒周期。

安装前核对客户端当前文档中的要求，尤其是机型、固件、KUAL 和 linkss。已越狱不等于已满足全部前置条件。

## 接入流程

1. 确认设备型号、固件及实际屏幕分辨率。
2. 按上游说明准备设备客户端。
3. 在 InkStack 中配置目标图片尺寸并生成测试画面。
4. 将客户端的 `IMAGE_URI` 指向 InkStack 的图片地址。
5. 配置刷新日程，检查设备能否访问图片服务。
6. 实机验证显示、休眠、RTC 唤醒、断网恢复及正常阅读模式切换。

纯局域网部署还需要检查客户端的连通性探测配置，避免把“不能访问公网探测地址”误判为“不能访问局域网图片服务”。

## 发布与安装的区别

网页上的“发布”指更新设备将下载的图片，不等同于向 Kindle 刷写固件。

客户端安装、配置文件生成或传输可以在后续增加，但不会因发布图片而自动安装脚本或修改设备系统。

## 首次验证记录

接入时记录型号、固件、客户端版本、分辨率、刷新间隔、缓存行为及多轮休眠唤醒结果。服务端请求成功不能单独证明 Kindle 已显示画面或进入低功耗休眠。
